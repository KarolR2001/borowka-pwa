# Definition of Done

Pakiet prac jest zakonczony, gdy:

- funkcja dziala w przewidzianych rolach;
- niedozwolone role sa blokowane po stronie Firestore, gdy funkcja dotyczy danych;
- walidacja poprawnych i blednych danych jest sprawdzona;
- obsluzono stan ladowania, pusty, bledu i braku uprawnien;
- wykonano odpowiednie testy automatyczne;
- wykonano test manualny, jesli dotyczy interfejsu lub wdrozenia;
- nie ma sekretow w repozytorium;
- dokumentacja i `postep.md` sa zaktualizowane;
- zmiana jest gotowa do przegladu przed polaczeniem z `main`.
