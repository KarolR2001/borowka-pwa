# Definition of Ready

Pakiet prac moze rozpoczac implementacje, gdy:

- wymaganie jest opisane w PRD albo rejestrze decyzji;
- wiadomo, ktore role korzystaja z funkcji;
- wiadomo, czy funkcja dziala online, offline czy w obu trybach;
- wiadomo, jakie dokumenty Firestore odczytuje i zapisuje;
- wiadomo, czy zmienia kwote, stan, wyplate albo historie;
- opisano zachowanie przy bledzie;
- okreslono minimalne kryteria akceptacji;
- zidentyfikowano wplyw na Security Rules;
- zidentyfikowano wplyw na migracje i starsze wersje danych;
- nie ma nierozstrzygnietej sprzecznosci blokujacej.
